# 浦仕章 · 个人主页

个人视觉创作简历单页（韦斯·安德森《犬之岛》电影视觉 · Level 2 强烈动效）。

- **入口**：`index.html`（单文件，双击本地即可打开；部署到 GitHub Pages 后即为个人主页）
- **说明**：纯静态、无构建步骤；在线依赖 Google Fonts 与 GSAP/anime/Three.js 的 CDN（加载失败自动降级，页面始终可用）
- **部署**：本目录整体作为仓库根目录推送 GitHub 并开启 Pages（详见 `..\发布计划-GitHubPages.md`）

> 源工程：`D:\OI_web`（含开发日志与历史版本备份，不随主页发布）
